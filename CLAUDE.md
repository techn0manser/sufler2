# Суфлёр питча

Одностраничное приложение (`index.html`) для Chrome на Android: голос в блютуз-наушнике ведёт говорящего по тексту питча. Хостинг — GitHub Pages из ветки `main`, правки коммитятся прямо в `main`.

## Как устроено
- **Текст** — константа `DEF` в `index.html` (слайды `#Название|секунда`), делится на фразы и «куски» по знакам препинания.
- **Распознавание** — локальная модель Vosk (`vosk/`, две части архива), словарь ограничен словами питча. Запасной вариант — Web Speech (Google), переключатель в настройках.
- **Озвучка** — запись голоса пользователя: файл выбирается на телефоне и хранится в IndexedDB (в репозитории его нет), разметка по словам — `voice/timings.json`. Запасной вариант — синтезатор.
- **Движок** (`engine`, `say`, `track`): голос говорит кусок за куском, ждёт говорящего (`gate`), при тишине повторяет фразу с начала (`relead`), после двух повторов ведёт по плану (`auto`). Между слайдами пауза и сигнал.
- **Офлайн** — `sw.js` кэширует страницу, модель и разметку.

## Важные решения (не откатывать без причины)
- Голос никогда не перескакивает вперёд и всегда начинает фразу и слайд с первого слова.
- Одиночному первому слову новой фразы и первым трём словам нового слайда из распознавания не верим: модель их «угадывает».
- Темп записи держится в пределах 0,85–1,08; говорящего не подгоняем.
- Запись голоса в публичный репозиторий не кладём.

## Проверка
- `node test/sim.js` — симуляция говорящего с подменой распознавания и синтеза.
- Настройка идёт по журналам с телефона (Настройки → Журнал). Формат строк: `[мс, событие, …]`; `rec` — распознано (позиция или -1), `say`/`st`/`en` — голос, `relead`, `auto`, `beep`.
- При каждой правке поднимать номер версии в подписи внизу страницы и в `dump()`.
